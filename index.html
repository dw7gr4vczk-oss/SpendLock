Security & iOS limitations

Prototype only.Prototype only. Frozen app indicators are simulated and do not block iPhone apps or prevent payments. A browser user can clear storage, modify code, or change device time. Bank connections are not implemented. Native iOS shielding requires Apple Screen Time authorisation and entitlements, and cannot be guaranteed tamper-proof.

A future native iOS app may request Family Controls permission and use ManagedSettings to shield selected apps. Apple requires entitlements; on an adult-owned iPhone, permission can be revoked. Never rely on this prototype to prevent spending. Local data is not encrypted or backed up; test with sample transactions. Existing v0.5 data is imported only if both versions run under the same browser origin.
